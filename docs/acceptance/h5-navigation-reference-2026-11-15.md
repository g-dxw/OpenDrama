# H5 参考站底部导航验收（2026-11-15）

## 交付

参考 https://test.dramnexos.com/ 的实际底栏，重做现有 H5 导航及独立追剧入口。

- 顺序为首页、发现、奖励、追剧、我的。奖励仍使用 siteFeature 开关；本机演示关闭奖励时显示4项，开启时为5项。
- 新增20px线框房屋、指南针、礼物、书签和人像图标；选中项使用32×2px顶部渐变短线、本站品牌色图标和白色文字，未选中为灰色。
- 对照390×844视口，导航72px、底部标识29.5px，合计101.5px；标签10px/15px、按钮55px高。底部显示 Made with MiniTV，并保留设备安全区。
- 新增 #mylist 与收藏/历史/点赞深链；与Profile各自高亮。游客进入追剧页显示书签和登录提示，未请求私有列表。
- 收藏和历史按30条分页，历史按原始分集记录推进offset，按剧聚合最新观看分集；继续播放携带episodeId。点赞计数只包含剧目，排除评论反应。
- 按身份重挂载并校验mounted/generation/token，拦截旧身份、旧页签的异步写入。
- 底栏支持方向键、Home/End；隐藏的奖励深链保留首项可聚焦入口。
